# Narration — demo video and tech video

The narrator is **AI narration: ElevenLabs text-to-speech** (voice “Daniel”, `eleven_multilingual_v2`, speed 1.1), generated by
`pnpm story:video` from this file. The end card of each video says so. The expert heard in the demo is the
**recorded audio of the live run**, and that expert's voice is **synthetic voice input (ElevenLabs TTS, voice “Matilda”)** —
labelled on screen wherever it plays.

Format: one `## <video>/<segment>` section per narration segment. `Sources:` lists the committed files the segment's
claims come from. Lines starting with `> ` are spoken. `{{path}}` is replaced by the value read from the evidence
(scripts/story/lib/evidence.ts) at build time. The build **fails** if a literal number in a spoken line does not appear in
one of the segment's cited sources.

## tech/arch
Sources: plan.md
> One Node service. Screen and activity signals feed a decision context; a hypothesis engine ranks questions by information gain; only a deterministic gate can authorise speech.
> Z3 and the expert's own words build the rulebook that drives the tutor and an MCP guardrail — all on an append-only ledger.

## tech/gate
Sources: docs/evidence/live/SUMMARY.txt, docs/evidence/live/rerun-2026-10-04/ACCEPTANCE.txt
> The gate needs every condition: silence, an idle screen, no typing, a breakpoint, a valuable question, and budget. In the first live runs it decided within {{live.gateP95}} at p95; in the re-run, {{rerun.within250}} decisions met the 250 millisecond bound, and three waited behind slow production round trips.

## tech/nonce
Sources: plan.md
> The voice agent's brain is our thin custom LLM. Real requests to this build: no credentials, rejected. No authorisation, skip turn. A valid one-time nonce, the exact question. The same nonce again, skip turn.
> On production, an unauthorised turn stayed silent for {{preflight.quiet}}.

## tech/z3
Sources: plan.md, PROGRESS.md
> Z3 checks the confirmed rules within the domain constraints and returns witnesses: undecided cases, real conflicts, and thresholds. Coverage closes only when all four criteria hold.
